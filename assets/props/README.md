# Fatal Vow prop batch

This directory preserves the untouched Meshy batch and its deterministic,
props-only production derivatives.

- `source/`: exact 8,094,304-byte Meshy GLB, SHA-256
  `f6e86e2a7a65061b8575ecbf3afd5d32e396716b21f57353718d3e9f66cfbd1a`.
- `processed/`: twelve independent, centered static GLBs, manifest, validation,
  and visible contact-sheet evidence.
- `../../tools/process_prop_batch.py`: reproducible 4x3 spatial splitter and
  512px texture optimizer.
- `../../tools/validate_prop_batch.py`: hash, structure, texture, and triangle
  conservation gate.

The untouched source contains 2,584 triangles. Processing removes one isolated
triangle visually identified beside the beetle-venom vial and preserves 2,583.
No arms, rigs, skins, or animation tracks are introduced. The outputs are
processed candidates; gameplay scale, grip sockets, and human acceptance remain
separate downstream decisions.
